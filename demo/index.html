Terminal-first DevSecOps toolkit

Scan repositories. Correlate risk. Plan remediation.

DevSecKit pairs a practical scanner CLI with an extensible security platform: a plugin SDK, an event-aware orchestrator, a documented risk scoring formula, and a remediation workflow with guardrails and RBAC. Stdlib-only Python — no runtime dependencies to install.

    Risk scoring

    Deterministic, documented formula from risk_engine.py — no opaque ML scoring.

    exploitability = min(10, max_severity_weight × 0.9 + 1.2 if known_exploits)
exposure       = min(10, 4.0 + distinct_plugin_types × 2.0 + 1.2 if internet_exposed)
business_impact= min(10, max_severity_weight × 0.7 + 1.2 × finding_count + 1.0 if sensitive_data)

composite = exploitability × 0.4 + exposure × 0.25 + business_impact × 0.35

severity:  composite ≥ 8.5 → CRITICAL · ≥ 7.0 → HIGH · ≥ 4.5 → MEDIUM · else LOW

    Remediation workflow

    From correlated risk to pull request — each stage below is labeled by what actually runs today.

    1. 1. Risk correlated implemented

      Findings sharing a rule_id are grouped into one UnifiedRisk.

    2. 2. Fix guidance generated implemented

      Deterministic heuristics in ai_module.py — labeled as suggestions, never as confirmed facts.

    3. 3. Remediation plan drafted implemented

      Target files, patch summary, and validation steps assembled in remediation.py.

    4. 4. Guardrail validation implemented

      Blocked paths (.github/workflows, .env, secrets, etc.), file-type allowlist, and repo-root containment checks in guardrails.py.

    5. 5. Dry-run preview implemented

      POST /api/v1/remediations/preview returns a preview PR URL/branch without creating anything.

    6. 6. Real PR creation requires configuration

      Only runs with GITHUB_TOKEN set, remediate:apply RBAC permission, and safe_to_auto_apply (MEDIUM severity only); otherwise it reports back without creating a PR.

    Quick start

    Exact commands from the repository README.

    Clone the repository
    git clone https://github.com/imharshitaa/DevSecKit.git
cd DevSecKit
chmod +x run devseckit
    Add to PATH (zsh / bash)
    export PATH="$PWD:$PATH"
    Add to PATH (fish)
    set -gx PATH (pwd) $PATH
    Run the scanner CLI
    run devseckit
    Launch the platform API
    export DEVSEC_API_TOKEN='change-me'
python3 -m devsec_platform.api

    DEVSEC_API_TOKEN is required for every /api/* request (sent as Authorization: Bearer <token> or X-API-Key). No credentials are included here — set your own value before starting the server.
